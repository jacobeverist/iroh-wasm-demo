iroh in the browser

The Rust p2p library iroh compiled to WebAssembly, imported by a plain JavaScript module, and driven entirely from this page. Open the devtools console — node is on globalThis, so you can call the API by hand.

Browsers cannot open UDP sockets, so iroh has no way to hole-punch here: every connection is tunnelled over a WebSocket to a relay. Traffic stays end-to-end encrypted, so the relay forwards bytes it cannot read.
