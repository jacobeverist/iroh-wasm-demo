iroh gossip in the browser

The Rust p2p library iroh and iroh-gossip compiled to WebAssembly, imported by a plain JavaScript module. Everyone who joins the same room name joins the same gossip swarm, and messages propagate peer-to-peer. Open the devtools console — node and room are on globalThis.

Gossip can't find the swarm for you: joining needs one bootstrap peer already on the topic. The first tab joins alone; later tabs use the share link, which carries a bootstrap id. Browsers are also relay-only — no UDP in the sandbox means every connection is tunnelled over a WebSocket to a relay, still end-to-end encrypted.
